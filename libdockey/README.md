# libdockey

Reusable Android document capture / result kit (`DocSdkSession`, `DocumentGuideView`, `ResultParser`, …).

Pulled automatically when your app applies:

```gradle
apply from: 'https://raw.githubusercontent.com/identixia-IDV/ID-Document-Recognition-Liveness-Detection-Android/main/install.gradle'
```

Local sample builds use the `:libdockey` module in this repo.
